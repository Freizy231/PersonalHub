# ADR-0012：生活工具、独立情报与可选 API 助手

2026-11-12｜v0.12.0｜状态：采用。用户最新指令优先于旧版 Ollama 默认与逐小版本等待规则。

## 背景与决定

用户授权持续功能开发、页面美化前暂停；明确没有外部财务工具，选择 Hub 轻量账本；AI 改为调用 API，不部署本地模型。音乐已取消，社区与可改代码 Agent 仍冻结。

1. 财务为非 Resource 的独立私有领域，收入/支出分类、整数最小币值交易、分类月预算、月报、回收、独立 JSON 导出与仅追加导入。它不进入普通搜索/Activity/关系/AI/普通ZIP。当前 DB 明文，由本机文件权限保护，**不是加密账本**。需要加密时单独设计，不复用/解锁真实日记库。只支持 CNY/USD/EUR 两位与 JPY 零位，币种分别统计，无换汇/银行同步/多账户转账。
2. 运动计划和实际记录各有独立事实表。计划可引用既有 Task/Event，不能复制共享任务/日程，不能自动完成。取消计划不抹去实际记录；统计仅未删实际记录。月训练列表按日期展示，原日历显示显式关联的 Event；未关联计划不冒充公共 Event。
3. 新情报中心与旧 GitHub 采集器隔离。原 Collector 仍是旧库唯一写入者；新中心显式只读导入四表全字段与 NULL，稳定 UUID 映射。原库未切换、未迁移、未双写。每次旧库变动作为新批次留存，不把重复批次当新原始事实。缺失原始 API JSON 保留 null，不能从 DB 行伪造。原始旧行在 intel_legacy_rows；标准化快照中 run_id 不假造跨库 FK。
4. RSS/Atom、HN、arXiv、Hugging Face 为独立适配器，手动单批采集；页面 GET 不采集，默认新来源关闭。HN20项、HF/arXiv默认50项、Feed最多200项；来源冷却60秒，整个采集120秒。失败/部分成功有状态，重启中断记录不自动重发。Reddit/Lobsters/Product Hunt 明确未接入，需要接口权限与维护评估。当前不新增定时网络工作器或 GitHub 写入替代。
5. 同平台同名累计指标可显示观测差值，零基线相对增长为 null，负差值不裁剪。downloads 滚动窗、trendingScore 不伪装累计增长，不把平台热度相加。同目标只建立关联，保留各来源资料和快照。
6. AI 是兼容 Chat Completions JSON 协议的通用 API 适配层：完整 HTTPS endpoint、模型、写入式密钥配置；不内置服务商、不下载模型。默认关闭，仅在页面明确确认五分钟发送预览后联网；不支持任意协议、流式工具、Agent、命令或自动写库。私密库/财务/项目路径不允许作为上下文。问题自身也会发送，界面明确提示。
7. API 密钥不可变文件 mode0600 存 config/assistant-secrets/UUID，DB仅存引用。更换 endpoint 必须重新绑定密钥；恢复快照缺少密钥时有效状态关闭。所有完整备份/普通导出/源码包都排除该目录；用户自行在服务商撤销旧密钥，解除引用不等于撤销。网络拒绝代理环境、重定向、非公开 IP；DNS校验后固定连接IP，保持TLS SNI与Host，不自动重试。
8. 发送预览最多8项、每项6000字符、合计24000字符（含标题），保留当前版本/hash。确认持久化一次性运行预约后才发网络请求；重启未知状态不可自动重试。取消停止本地请求，不保证远端未处理/未计费。结果只在进程内临时保留且再次校验版本/隐私/配置/会话；模型引用须人工核实。无请求正文/回答/密钥落日志或运行表。
9. 先交付本地 FTS 选材+显式资料问答，不先引入向量依赖；P4-05 需至少20个人工标注问题与检索收益证据，目前无该证据及 embedding 选择，因此保持门禁后置，不能标为 RAG 已完成。

## 迁移与恢复

只新增 0011_finance_exercise、0012_intelligence_assistant；0000～0010不改。所有新表独立，现有资源表无重建。沿用停写锁、完整v3快照、全行/索引/触发器保护、副本演练、事务升级、完整备份、全新根恢复。无在线 downgrade。账本/情报原始载荷在完整明文DB备份中；vault仅密文，不代解锁。

## 后续条件

功能验收后才讨论统一搜索摆放/博客式笔记/密度/主题包装。凭据来源和真实网络连通需用户在本机配置确认；平台不可用不伪装成功。不因免费开源讨论提前选择许可证或实现社区/自修改Agent。
