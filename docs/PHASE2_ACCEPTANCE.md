# Phase 2 统一浏览器验收（v0.8.0）

2026-11-12｜开发、自动检查、活动库升级、完整备份和隔离恢复已完成；下面各项等待本人在桌面浏览器验收。无需逐小版本确认。Phase 3 不在本次范围。先用虚构笔记和可信测试 PDF，勿把私密日记写进普通资料库。

## 1. 启动

在项目根目录，先在旧服务终端 Ctrl+C 停止旧 Hub，再运行：

```bash
backend/.venv/bin/python -B -m backend.manage check --data-root runtime/personal-hub
backend/.venv/bin/python -B -m backend.manage serve --data-root runtime/personal-hub --port 8765
```

本工作区已是 `0007_phase2`，**不用 init，不用重复 upgrade，不用重新安装依赖**。服务启动后打开本机 `runtime/personal-hub/config/launch-8765.url` 中的新完整地址；不要分享该文件或地址。浏览器应显示 v0.8.0。旧版本进程不会自动加载新增 API；启动失败先确认旧终端已退出，不删除维护锁。

其他仍在 0005 的部署：先停服，按 OPERATIONS 显式 upgrade（内置备份和副本演练），成功后再 serve。缺库/未知版本应拒写，不能 init 覆盖。旧 Streamlit 情报工具仍按根 README 单独启动。

## 3. Library：PDF、书籍、网页和课程

- [ ] 将文献设为“在读”，填写合法当前页；越界页拒绝且不覆盖原值；增加/解除一页书签；下载原件与导入文件一致。
- [ ] 设置中登记本机实际已安装的白名单阅读器，文献详情先预览再确认启动；取消不启动，过期预览要求重试，一次确认不重复启动。启动仅说明发起进程，不自动更新进度。
