# ADR-0005：独立私密 Note 密文容器

日期2026-11-12；状态：v0.5实现契约。用户已选择独立加密库与解锁密码，v0.4浏览器验收已确认。

## 决策与边界

私密日记/树洞沿用Note领域（UUID、标题、类型、日期、正文、版本、历史、软删），使用独立VaultNoteStore适配器，不写普通Resource/Note/Activity/幂等表，无跨库占位和反向关系。标签、集合、跨资源关联、搜索索引尚不实现；未来若加入必须全部位于密文内。普通Note API保持personal。首版是小型文本库，不是通用文件加密或完整加密SQLite。

固定格式PHV1：8字节魔数`PHVAULT1` + 16字节随机salt + 12字节随机nonce + AES-256-GCM密文（含16字节认证tag）。完整36字节头作为AAD。Scrypt N=131072/r=8/p=1/32字节密钥，由cryptography审核过的实现提供（算法没有自行实现）；每次设密/改密使用新salt，每次保存新96bit nonce。头不携带可调KDF成本，不让损坏输入控制内存预算。解密后为UTF-8 JSON，内含schema_version=1、notes、operations；真实标题/日期/历史/正文/hash/幂等payload摘要全部在其中。salt/nonce/格式/密文长度/文件mtime和库存在性可见，无法隐藏使用频率。AEAD不能防止攻击者回滚整份旧密文；清单hash也不是独立签名。

密码12～256字符，不trim、不自动改字符；只能在本机密码框输入。遗忘无后门/云托管/默认恢复密钥。Scrypt约128MiB工作内存，性能须以本机测量为准。新增cryptography/cffi/pycparser仅安装新backend环境并以PyPI wheel SHA-256锁定，不升级旧依赖。不是声称做过第三方安全审计。

## 生命周期与并发

服务重启默认锁定。解锁只绑定当前LocalAuth会话（同cookie的标签共享会话；新面板挂载会撤销遗留解锁并要求重新输入），其他会话看不到内容。5分钟无操作锁定，单次解锁最长30分钟；状态轮询不续期，页面活动显式touch续空闲期限、不续绝对期限。后台每秒检查，所有私密操作前后检查期限及普通会话；退出/服务关闭立即锁定。浏览器隐藏、离开私密面板/刷新卸载立即清空内存并尝试锁定，锁请求失败仍由服务器期限兜底；同cookie其他页面正常网络下每秒轮询清空，网络挂起时使用客户端已确认期限兜底。浏览器挂起/离线无法保证隐藏页面的物理内存立即擦除。

进程内RLock串行访问，独立vault-session.lock flock在解锁期间持有，拒绝第二进程同时解锁；不能删除锁文件解除。每次读写验证当前密文hash，外部修改立即锁定，不用缓存覆盖。解密/加密/KDF在工作线程；一次容器16MiB上限，最多1000笔记、4096幂等写入（不静默淘汰）、每正文200000字符；达到上限保留所有历史并明确拒绝，后续容量升级须新设计。

## 持久化与失败

仅`vault/vault.phv`为活动容器，目录0700/文件0600、逐级NOFOLLOW和普通文件检查。先在同目录O_EXCL写随机`.tmp`密文，flush/fsync，设密用link拒覆盖，保存/改密原子replace，最后目录fsync。替换前异常保持旧容器；替换后fsync异常为提交结果不确定，立即锁定，重新解锁核对幂等操作，禁止界面假成功。失败临时文件为密文且不自动清理，纳入完整快照。明文不写临时文件、SQLite/WAL、日志或浏览器持久缓存。不能承诺Python/浏览器内存零化、swap/root/同账户恶意进程防御，需系统锁屏/磁盘加密配合。

写入带UUID Idempotency-Key及expected_version，幂等记录与Note在同一密文原子提交；同key不同payload拒绝，重试返回当前事实，旧编辑不能覆盖新版本。修订是完整不可改历史，恢复历史先入草稿再明确保存新修订。软删可恢复，无永久删除/自动保存。改密需旧密码验证+新密码重复确认+UI明确确认；使用新salt/key原子重加密后锁定，旧备份仍需旧密码，无法远程撤销历史副本。

## 备份恢复

完整Hub快照扩为hub-files.json version2，包含notes树及整个vault树密文/hash/大小，最后发布完成清单，停服务取维护锁与笔记文件锁。version1旧快照继续验证恢复；version1若出现vault文件拒绝（不能静默漏库）。恢复只到全新根，带HUB_INCOMPLETE保护，保留密文原样；解锁内容校验另需对应密码，不将hash校验冒称解密验收。备份不含密码、会话/launch和锁。无明文私密导出、在线恢复/覆盖、云同步、AI访问，界面仅提示停服完整备份命令。活动用户库不自动设演示密码。
