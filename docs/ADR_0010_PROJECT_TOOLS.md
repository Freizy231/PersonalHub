# ADR-0010：项目专业工具启动 / v0.10 / P3-02

2026-11-12｜已实施，v0.10交付。用户确认v0.9浏览器验收完成，授权下一步；先功能后统一包装。此前开源/内嵌Agent改造仅讨论，本版不实现。

固定适配器：GNOME Terminal（干净Bash）、VS Code（禁用扩展保留工作区信任）、Codex（GNOME Terminal内交互、read-only/on-request/no-daemon，无初始prompt/exec/自动任务）。只从服务端固定候选路径发现程序，API不接受任意可执行路径/参数/环境变量/shell。已核对本机命令路径与终端/Codex帮助；不下载安装，不启动真实用户项目做自动测试。

项目目录先逐组件NOFOLLOW验证，预览绑定目录路径与dev/inode、项目版本、profile版本和可执行文件身份（解析路径及stat指纹）；60秒有效，启动前再次验证。配置首次登记或程序更新重绑须用户明确保存，不在GET自动注册。父目录拒绝可由其他普通用户改写的路径（/tmp sticky例外仅测试/个人目录路径按安全遍历验证）；程序固定候选可以是安装器symlink，但解析后路径及程序身份必须固定。Snap Code作为明确适配器走固定snap run code，不把任意snap参数开放给用户。

新增0009_project_tools，仅新增配置/预览/历史三表，不改0000～0008或重建资源表。profile/preview创建使用共享幂等键，配置改动CAS；confirm以preview_id做一次性执行键：先事务写starting→事务外Popen→记录结果，重复/并发只读已有记录。崩溃/结果写入失败留starting，API投影uncertain，不自动重执行。外部进程不能与SQLite整体原子，不能保证GUI实际打开；started只表示启动请求已发起。

归档/回收/私密项目不得新启动，历史和幂等重放按当前项目隐私过滤；未知新版库拒写。目录/程序在预览后变化拒绝，确认前重新读权限与身份；Popen使用参数数组shell=False、受控环境、DEVNULL和独立会话，不收集工具输出。工具启动后其配置/访问能力仍由外部程序决定，不能把这些校验宣传为恶意项目执行沙箱；界面提示只打开可信项目。真实桌面GUI待用户验收。

完整备份v3纳入三表和受管文件；启动配置是机器相关，不进普通知识ZIP，完整灾备恢复不自动启动，换机器须重新绑定。活动根不写演示配置/预览/启动，不解锁真实vault。按既有备份→演练→事务升级→全表核对→完整快照→新根恢复交付。
