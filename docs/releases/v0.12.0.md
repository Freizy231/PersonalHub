## 启动

活动库已升级并ready，正常重启即可，不需要init或重复迁移：

```bash
backend/.venv/bin/python -B -m backend.manage serve --data-root runtime/personal-hub --port 8765
```

从本机 `runtime/personal-hub/config/launch-8765.url` 打开新入口，若旧服务还在先在原终端Ctrl+C。不要公开入口URL或密钥。
