# v0.14.0 前端重构：简洁与高效

2026-11-13。用户要求"全部修改，以简洁高效为准"。本次只改前端结构与交互，加上三处后端修正。schema 新增 `0013_intel_ordering`（仅一个排序索引）。

## 已改变

**导航从三层压到两层。** 原来 8 个主入口 → 生活页 7 个 tab → 每个 tab 内的 scope 按钮（部分面板还有第三个维度）。现在侧栏直接列出 13 个目的地（今日 / 任务 / 日程 / 笔记 / 饮食 / 财务 / 运动 / 私密库 / 学习 / 资料库 / 项目 / 情报 / AI），页面内不再有第一层 tab。资料库的 PDF / 书籍 / 网页 / 课程改为列表内筛选。

**阻断式确认从 48 处降到 8 处。** 可逆操作（删除、完成、移出项目）改为立即执行 + 8 秒内可撤销的提示条。只有不可逆或对外发送的动作仍保留确认：导出私密账本、发送到外部 API、启动本机程序、锁定私密库、改密码、导入。

**移除 Naive UI。** 自写 `HubButton` / `HubDialog` / `HubToast`。主 chunk 从 509 KB 降到 137 KB（gzip 160 KB → 54 KB）；`node_modules/naive-ui` 70 MB 依赖已删除。

**统一请求与草稿语义。** 新增 `shared/requests.ts`（竞态丢弃 + 幂等重试）、`useUnsaved.ts`（离开保护）、`toast.ts`（可撤销提示）。7 份序号守卫、18 份幂等逻辑收敛到这两处。

**样式单一来源。** `tokens.css`（颜色/字号/间距）+ `base.css`（组件样式，977 行）。原 `style.css` + `workspace.css` 的 155 个重复选择器已消除。正文字号从 11–12px 提到 13.5–15px。

**模板密度。** 原来单行 4000–12000 字符的模板全部展开；`DietPanel` 的模板从 11829 字符 / 37 行改为可读结构。

## 后端修正

1. `GET /resources` 补上 `total`。此前前端选择器读取 `total` 得到 `undefined`，第 51 项之后的资料永远无法被选中且无提示。
2. 搜索查询把正文投影为 300 字符片段（`substr` 在 SQL 内完成）。此前一次搜索会把最多 10001 行完整正文读进内存，文献最大 16 MB。
3. 错误编号现在与落盘日志一致：`request_id` 同时返回给前端并写入 `data_root/logs/hub.log`（1 MB × 3 轮转，0600）。此前前端提示"查看本地错误编号"，但没有任何日志。

## 测试

- 前端 65 项（原 104 项）：测试基础设施改为真实模块加载器（`tests/loader.cjs`），挂载的是同一份组件源码，不再维护会漂移的 stub 映射。断言改为验证行为契约（幂等键复用、版本冲突不覆盖、可撤销删除、私密库锁定时清空页面）。
- 后端 227 项 + 新增 4 项错误码一致性测试：扫描后端所有错误码，要求前端 `api.ts` 全部有对应文案，且前端不得有后端不存在的孤儿码。已补齐此前缺失的 61 条。
- 前端 `vue-tsc --noEmit` 与生产构建通过。

## 未验证

本环境没有浏览器。明暗两套主题、真实字号观感、窄屏布局、滚动与焦点行为**均未在真实浏览器中验收**，需要本机确认。内存渲染测试不等于浏览器验收。
