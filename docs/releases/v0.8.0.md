## 交付行为

- 补齐共享知识基础：Task 等普通资源复用 Tag；有序 Collection、related/material/output 关联、唯一 practice 学习任务边、稳定 UUID 链接与 Markdown 反链；普通 FTS5 trigram 搜索，中文短词明确为字面扫描，后台增量更新与手动重建。
- Library：批量 PDF 流式导入、100 MiB/文件与20文件/UI批次、SHA-256去重、持久提取任务/失败重试/取消/重启补偿、原始与人工元数据、阅读状态/手动进度/书签/下载/关联备注；无文件书籍、网页手填元数据、课程；只调用明确配置的本机阅读器，预览后确认。
- Learning：目标、路线、有序无环知识树、验收标准、材料/成果、共享练习任务、手动学习时段、有证据的掌握验收、不可覆盖的历史版本/标准快照、Markdown阶段复盘。时长或Task完成不会自动变为掌握。
- 界面：资料库/学习/资源详情/搜索、快捷键；首页增加在读、学习计划、本周成果三个可选组件，旧五组件只读兼容、默认新项隐藏；设置提供普通资料ZIP与完整备份恢复命令、阅读器配置。
- 数据：0005→0006→0007；24个新增业务/投影表+FTS虚表及shadow表，Resource扩展kind CHECK；完整snapshot manifest v3覆盖notes/vault/library及在途/孤儿，普通ZIP含普通事实/修订/文献/关系/证据/提醒/合法首页配置。

## 技术决策与边界

没有新增/升级依赖。PyMuPDF未安装且官方PyPI网络不可达，本期使用已安装系统Poppler；独立子进程加CPU/内存/输出/页数/时间预算，no_new_privs、Landlock和seccomp隔离失败即拒绝，不静默降级。只处理本地文件，不调用云AI/翻译/远程元数据。密码PDF显示password_required，不接收密码；用户可在专业软件解锁另存后导入。扫描PDF无文字即no_text，无OCR。

practice通过learning_node_tasks为唯一权威，未给Task加单值learning_node_id；支持同一练习关联多个知识点。所有普通服务过滤当前隐私/删除、学习祖先及文件完整性，隐藏证据的验收/统计/导出不泄漏；vault仍独立密文，无普通身份/索引/关系。不可覆盖历史文件、CAS与原key重试规则延续；多表单草稿聚合、迟到编辑响应和子树深度已补查。

不做OCR/高亮批注/网页全文归档/完整内置阅读器/学习计时器/Project/RAG/AI/社区；手动学习时段已满足本期。阅读器固定四种程序，本机GUI实际启动及非evince命令兼容性待用户桌面核对。ZIP仅导出，恢复用完整快照，没有合并导入。
