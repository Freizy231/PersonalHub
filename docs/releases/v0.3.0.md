## 本版行为

Life新增日程视图：月历选日、分页议程、全天/具体时间/跨日、地点/状态、普通Task关联、编辑/冲突、软删除/恢复与JSON。首页增加今日日程。所有时间为明确半开区间，全天结束UI含当日、API为次日，定时UTC存储、浏览器时区显示；新输入DST不存在/重复时刻拒绝，未改变的原始秒/微秒保留。

Task/Event行可设置独立一次性站内提醒；首页收件箱、已读、历史、取消与JSON。约5秒处理、15秒只读刷新，24h内到期delivered、超24h missed；状态入库不表示浏览器已看见。并发/重启不生成重复通知。完成/取消/改期/软删除取消pending，恢复不自动重启；只改标题不取消。关联不传播任务/日程完成状态，隐藏目标不泄漏ID/标题。

无系统通知/复杂重复/CalDAV、月格事件摘要/拖拽、Note/vault、PDF/学习/AI/社区；不声称已实现完整Phase1。私密日记仍采用待实现的独立加密库，敏感录入关闭。无新增或升级依赖，锁文件仅应用版本元数据变化。
