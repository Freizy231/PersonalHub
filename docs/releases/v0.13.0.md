- 暖纸色内容区、石墨色导航、青绿强调和小量陶土色细节；亮/暗主题统一，本地SVG图标与CSS品牌，无远程字体/图片/新依赖。
- 首页真实日期与问候、清晰主动作、两栏组件和留白；原组件显隐/排序与真实数据保持，窄屏单列，不虚构统计。
- 搜索放在右上日期左，范围下拉+Enter/Ctrl K，结果自动带入关键词/类型；资料库和固定资料页不再重复标题查找，业务筛选继续可用。
- 笔记从标题进入文章式阅读，返回/编辑明确分开；日期/类型/标签和正文排版突出。原Markdown编辑/历史修订/冲突/保存仍原功能。

- 全模块统一输入、按钮、分页、空状态、折叠区域、列表、焦点与响应式。安全确认、私密库提示、账本明文提示、API发送预览保留。

