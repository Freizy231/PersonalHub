## 新增与行为

首页已有真实“今日任务”；Life管理全部/今日/未来计划/逾期/已完成/回收站，支持创建、编辑标题与说明、优先级、计划日、截止日、状态、完成/重开/取消、加入今日、软删除/撤销/恢复和JSON导出。数据保存在本机SQLite，重启保留，无AI/联网依赖；没有演示任务。

今日按planned_date，不把所有到期项自动挤入日计划。日期截止在任务自身时区当天结束后才逾期，精确截止支持API并归一为UTC。任务说明目前为纯文本，不提供HTML渲染。没有日历/提醒、标签分类、首页组件重排、Note/日记/vault、PDF、学习或AI。私密加密方案已选但未实现，录入仍关闭。

创建用持久幂等键防重复；编辑/完成/删除/恢复用expected_version防覆盖。网络失败保留草稿与原创建请求；冲突后保留草稿并要求核对，不自动覆盖。写入失败任务不会假勾选成功。删除仅进回收站，无永久清理。

## 使用、回退和下一项

当前新库已升级、dist已构建。**先在运行Personal Hub的终端Ctrl+C停止旧进程**，再从项目根执行：

```bash
backend/.venv/bin/python -B -m backend.manage serve --data-root runtime/personal-hub --port 8765
```

用本机编辑器打开runtime/personal-hub/config/launch-8765.url，在本机浏览器打开其中完整地址，不分享凭据。旧进程不会自动载入新API，必须重启；无需重复init。其他0.1部署先按[OPERATIONS](../OPERATIONS.md)执行显式upgrade，已升级时重复upgrade安全返回up_to_date。

回退代码保留新库和备份，不运行downgrade；旧程序不能读取新Task。真实回退新库必须先保全升级后事实/当前备份/JSON，再停机隔离恢复匹配旧程序与升级前库，不能覆盖唯一新资料。旧情报工具未修改，可独立继续使用。
