# v0.13.1：日常操作与可读性修正

2026-11-12。按用户“通篇检查有哪些不人性化的地方，直接修改”授权，对八个模块及共享组件做源码与交互审查。延续 v0.13 的视觉方向，优先减少操作负担、误触与草稿丢失。本版不是新一轮业务扩张。

## 已修正的问题

| 原有体验问题 | 当前行为 |
| --- | --- |
| 文字、元数据和操作缩至 8–11px，长期阅读吃力 | 提高正文、辅助信息、表单和首页控件字号；文章正文桌面 16px，窄屏 15px。英文装饰信息仍低于正文层级 |
| 侧栏在较矮窗口中可能挤出底部入口 | 侧栏独立滚动、缩短装饰间距；窄屏图标有名称与提示 |
| 首页欢迎区占用较多首屏 | 收紧高度、缩短标题，保留日期、今日任务和快速记录主动作 |
| 小文字操作点击范围窄，操作淡化后不易发现 | 增加点击高度，任务和笔记操作保持可见；增加“跳到主要内容”键盘入口 |
| 生活分类只存在组件内，刷新、后退不可靠 | 分类写入 `?view=`，浏览器后退恢复；导航仍经未保存草稿确认 |
| 资料库分类返回默认 PDF，重复点击同一分类也提示放弃 | 分类写入 `?view=`；同分类点击不重置；首页“管理全部笔记”直达笔记分类 |
| 首页“安排今天”打开全部任务 | 进入今日任务范围，新建默认安排在今天 |
| 日程关闭、切换模块或刷新可能丢掉草稿 | 日程增加字段差异/提交不确定状态/进行中操作保护，传播至首页与全局离开守卫；明确取消才放弃 |
| 切换全天/定时日程重置已填写日期 | 保留当前开始、结束日期；定时默认 09:00–10:00 |
| 日程搜索结果只有泛化管理入口 | 固定链接直接打开该日程编辑，并定位它所在日期 |
| 首页任务、记录、日程共享一个 dirty 布尔值 | 按组件 ID 汇总；其中一个保存/关闭不会解除另一个草稿的保护 |
| 搜索结果页仍重复顶部关键词和分类输入 | App 中结果页只显示搜索条件，顶部为唯一主输入；独立组件仍保留可用表单 |
| 读取失败被混成无结果、输入新词后翻页条件混乱 | 明确加载/失败/成功状态；失败保留并标注上次结果；分页绑定已提交条件；过期响应不能覆盖当前请求 |
| 搜索维护动作与日常查找并列 | 索引重建放进“搜索不到已有资料？”折叠说明；无内容时不显示无用分页 |
| PDF/书籍/网页/课程详情被长列表埋住 | 查看详情时收起列表；返回保留当前列表及筛选，书籍等详情有明确编辑入口 |
| 编辑笔记失败或关闭后阅读上下文消失 | 编辑时保留文章阅读上下文；正文保存成功后仍使用现有刷新与历史版本流程 |
| PDF 页面每 5 秒无条件读取、错误也出现“暂无文献” | 仅可见且有待提取任务、无编辑/上传时轮询；失败不冒充空列表 |
| 运动计划需要手填任务/日程 UUID | 按标题查找、分页选择现有资料；当前不可见关联保留，不显示不可见标题，也不自动解除 |
| 运动列表只有原始秒数、米数 | 显示分钟/秒和公里/米；输入及存储契约仍为秒/米，避免改变已有精度 |
| AI 快捷提问覆盖正在写的问题 | 已有问题先确认替换；预览/发送期间禁止替换与清空 |
| AI 切换搜索后找不到已选项，超出 8 项无反馈 | 独立已选资料区可移除，达到上限有明确提示 |
| 关联查找框 Enter 触发保存/验收/AI 预览 | 学习证据、集合成员、饮食食材/食谱、项目关联、AI 资料框 Enter 只执行对应查找 |
| 周报重新生成覆盖草稿、离开无提醒 | 生成的周报纳入草稿保护；重新生成先确认替换，仍需复制到笔记保存 |
| 界面散落 kind/status/relation 原始枚举 | 搜索、关联、学习、AI 回答状态与情报阅读状态使用中文标签，底层字段保持 |
| 财务/运动/情报载入时显示空库，失败提示无直接恢复入口 | 增加读取中提示、可重试错误；读取失败不显示空数据结论，旧结果保留 |
| 长时间打开后的日期问候过期 | 顶部及欢迎区日期/问候每 30 秒或窗口重新聚焦时更新；各业务列表日期仍按其已有刷新时机读取 |

## 本机验收

停止原服务后，项目根目录启动：

```bash
backend/.venv/bin/python -B -m backend.manage serve --data-root runtime/personal-hub --port 8765
```

从 `runtime/personal-hub/config/launch-8765.url` 打开新入口，不分享凭据；Ctrl + Shift + R 加载本版构建，不需 init、upgrade 或重装。

1. 首页查看首屏任务与记录、侧栏短窗口滚动；“安排今天”和“管理全部笔记”应直接到相应范围。
2. 生活/资料库切换分类，刷新及浏览器后退，确认分类恢复；日程填入临时测试草稿后尝试取消/导航，拒绝放弃时保留。
3. 多个首页组件分别产生草稿，关闭其中一个仍应提示另一个未保存；不要在真实私密库内做测试。
4. 顶部查找与分类，结果页不重复输入；查无结果、失败重试、分页应明确。私密日记与账本不应出现在结果中。
5. PDF、书籍等打开详情不必向下越过整页列表，返回后筛选仍在；笔记编辑取消仍可继续阅读。
6. 运动计划通过标题关联任务/日程，原有隐藏关联不应被清空；查看分钟和公里显示。
7. AI 无需实际外发即可检查快捷问题替换、已选资料移除。若测试真实 API，仍必须单独预览确认，不能用真实私密内容。
8. 检查明暗主题、桌面两种宽度、浏览器放大至 125%/150%、较矮窗口、Tab 焦点与长内容换行；反馈具体页面即可继续修正。

无数据库变化；回退使用匹配旧源码与旧前端构建，不能恢复旧数据库覆盖本版新录入。
